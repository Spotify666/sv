# Photography

The six collection plates look for their images here on page load. A plate only
swaps to a photograph if the file actually loads, so missing files are harmless:
the plate falls back to its generated garment study.

Portrait, 3:4. Anything from 1200x1600 up holds at desktop width. Ask the
photographers for originals rather than the Instagram exports, which are capped
at 1080px wide and recompressed.
